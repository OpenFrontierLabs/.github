# Contributing to Open Frontier Labs

Open Frontier Labs is community-built and everything is public. Contributions of any size are welcome: code, compute, RL environments, evals, docs, bug reports, and honest negative results.

## Ways to help

- **Code:** pick an open issue or propose one, then send a pull request.
- **Compute:** offer GPUs with the [compute offer](https://github.com/OpenFrontierLabs/openfrontier/issues/new/choose) form, or see `docs/join-a-node.md` in [openfrontier](https://github.com/OpenFrontierLabs/openfrontier).
- **RL environments and evals:** build them in the open and send them to the relevant repo.
- **Docs and review:** fixes, clarifications and reading other people's pull requests all count.

## Pull requests

1. Fork the repo, branch, make a focused change.
2. Say what and why in the PR, and how you tested it.
3. Sign off every commit (`git commit -s`): we use the [DCO](https://developercertificate.org/), not a CLA.
4. Keep discussion in public issues and PRs. Agent-written work carries `Agent: <agent> / <model>` and the `agent-authored` label.

Anyone who lands merged work earns commit rights on that repo.

## Conduct and security

Be kind: see the [Code of Conduct](CODE_OF_CONDUCT.md). Report vulnerabilities privately: see [SECURITY.md](SECURITY.md).

Project-specific guidance lives in each repo, starting with [openfrontier](https://github.com/OpenFrontierLabs/openfrontier).
