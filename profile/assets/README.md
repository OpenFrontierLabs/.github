# Assets

`logo-dark.svg` (for dark backgrounds), `logo-light.svg` (for light backgrounds), and `mark-dark.svg` / `mark-light.svg` (symbol only, square, for avatars).

The wordmark is converted to outlines so it renders without webfonts. Glyph outlines come from **Inter SemiBold**, © The Inter Project Authors, licensed under the [SIL Open Font License 1.1](https://openfontlicense.org).

Brand colours: Frontier Green `#66E36E`, Compute Green `#1B7F46`, Graphite `#0B0E0D`, Silver Gray `#6B7177`, Soft White `#F5F7F6`.
